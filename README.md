# leonxlnx-high-end-visual-design-skill

> "싸 보이는" AI 디자인 금지 + 고가 에이전시 품질 코드 레시피.

## 이 스킬의 역할

AI가 코드로 만들었을 때 "왜 이렇게 싸 보여?"라고만 할 때,
이 스킬은 **고급스러운 코드의 정확한 기준**을 알려줍니다.

- "싸 보이는" AI 디폴트(Inter 폰트, 보라 그라디언트, 1px 회색 테두리) 금지
- 더블 베젤 카드, 매크로 화이트스페이스, 커스텀 모션의 정확한 레시피 제공
- 1순위 = 폰트 교체 (임팩트 큼, 리스크 작음)

## 누가 쓰면 좋은지

- **개발자**: AI로 코드를 만들 때 "왜 이렇게 싸 보여?"를 해결하고 싶을 때
- **비개발자 (개발자 협업 시)**: "더 고급스럽게" 대신 구체적 스타일 방향을 전달할 때
- **React/Tailwind/HTML 코드 생성**: "고가 에이전시" 품질 가드가 필요할 때
